# Message Bridge 0.1.1

This is the signed replacement for the original v0.1.0 release. It keeps
Message Bridge free, open source, local by default, and independently branded
while fixing operating-system trust failures in the downloadable builds.

Bundled bridge upstream revision:
[`verygoodplugins/whatsapp-mcp@e5f1a9a`](https://github.com/verygoodplugins/whatsapp-mcp/commit/e5f1a9aef5c78198ad27d52d40d4513d3b7e0e2f).

## Downloads

- **macOS Apple Silicon:** `Message-Bridge-0.1.1-arm64.dmg`
- **macOS Intel:** `Message-Bridge-0.1.1-x64.dmg`
- ZIP files are also supplied for both macOS architectures.
- **Windows 64-bit:** install from the
  [Microsoft Store](https://apps.microsoft.com/detail/9PBD74ZRV6ZT).
- Verify GitHub downloads against `SHA256SUMS.txt`.

No unsigned Windows installer is attached to this release.

## Release trust fixes

- macOS applications are signed with the Happy Webs Limited Developer ID
  Application certificate.
- Both macOS architectures are notarized by Apple and include a stapled
  notarization ticket.
- The release workflow rejects a macOS artifact unless strict signing,
  publisher, bundled-bridge, stapler, and Gatekeeper checks all pass.
- Windows is packaged with the reserved Message Bridge Store identity, checked
  on a Windows runner, and submitted to Microsoft for signing and delivery.
- Release credentials are held in encrypted GitHub Actions secrets and are not
  included in the source or installers.

## Included

- Unified local inbox for separately linked accounts
- Optional AI-assisted reply drafts
- Local business and customer memory controls
- Local MCP configuration for Claude Desktop, Codex, and other clients
- MCP access off by default, with separate per-account read and send grants
- GPL-3.0 source and bundled third-party licence notices
