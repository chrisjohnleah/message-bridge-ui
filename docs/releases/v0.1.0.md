# Message Bridge 0.1.0

The first public release of Message Bridge: a free, open-source desktop
interface for a local messaging bridge.

## Downloads

- **macOS Apple Silicon:** `Message-Bridge-0.1.0-arm64.dmg`
- **macOS Intel:** `Message-Bridge-0.1.0-x64.dmg`
- **Windows 64-bit:** `Message-Bridge-0.1.0-x64.exe`
- ZIP files are also supplied for both macOS architectures.
- Verify downloads against `SHA256SUMS.txt`.

## Included

- Unified local inbox for separately linked accounts
- Optional AI-assisted reply drafts
- Local business and customer memory controls
- Local MCP configuration for Claude Desktop, Codex, and other clients
- MCP access off by default, with separate per-account read and send grants
- GPL-3.0 source and bundled third-party licence notices

## Before installing

These first builds are **not code-signed or notarized**. macOS Gatekeeper and
Windows SmartScreen will therefore identify the publisher as unverified. Check
the SHA-256 checksum, download only from this GitHub repository, and proceed
only if you trust this project and its source.

This is unofficial compatibility software. It is not affiliated with,
endorsed by, or sponsored by WhatsApp LLC or Meta Platforms, Inc. Unsupported
or automated use may breach provider terms and may lead to account
restrictions. Use a non-critical account and assess the current terms yourself.
