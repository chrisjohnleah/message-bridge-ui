# Security policy

Please do not publish active session data, API keys, message archives, pairing
codes, or personal conversations in an issue.

Report a suspected vulnerability privately through GitHub's security advisory
feature for `chrisjohnleah/message-bridge-ui`. Include affected versions,
reproduction steps, and impact. There is no guaranteed response or support SLA.

Keep Message Bridge and its dependencies updated, use a non-critical messaging
account, grant the minimum MCP permissions, and review any AI provider's data
policy before sending conversation context.
